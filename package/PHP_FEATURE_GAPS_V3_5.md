# PHP v3.5 3領域ギャップマトリクス

判定は2026-11-02のソース確認時点。PHP互換対象の正式バージョンは未確定。比較オラクルはPHP 8.4.24。

| 領域 | 追加実装の例 | 未実装または未証明 | 認定 |
| --- | --- | --- | --- |
| 変数・演算子・配列 | 配列分解代入、展開、比較、union、整数ビット演算、前後++/-- | 参照・可変変数・全型/境界・代入演算子全網羅・配列循環・正確なPHP警告 | 不可 |
| 関数・スコープ | 初期値、named/variadic、global/static、closure/arrow | 参照渡し、型宣言、ジェネレータ、名前空間、クロージャー参照捕捉全対応 | 不可 |
| OOP | 継承、可視性基本、static、const、clone | interface、trait、abstract/final、enum、マジック全体、readonly、private同名衝突 | 不可 |

検証上の禁止事項：未実装コードを黙って受理しない。テスト期待値を都合よく修正しない。既存PHPのアダプタやALL独自言語処理系を無断変更しない。329件合格でも完全互換を認定しない。
