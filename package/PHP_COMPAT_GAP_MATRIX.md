## 判定基準

1. **実装済**：アダプタにコードが存在する（実行結果の正しさは別）。
2. **自己試験合格**：ALLのテストを実行し合格。期待値の書き換えで不具合を隠さない。
3. **実PHP差分合格**：同一コードを対象バージョンの公式PHP実行環境と比較し、型・出力・例外・警告・副作用まで一致。
4. **実アプリ合格**：PHPで開発した既存アプリ／ライブラリを無改変で実行し、その運用動作・性能を確認。
5. **完全互換認定**：対象とするPHPバージョン・言語仕様・標準ライブラリ・拡張・SAPI・互換範囲をユーザーが明示的に確定し、上記の差分基準に対して必要範囲を実証。

現状は**完全互換未達成**。この一覧は項目の優先度を確定する仕様変更ではなく、検証上の不足整理である。
