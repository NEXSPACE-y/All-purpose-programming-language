# ALL PHP v3.17 — 名前空間の実行時フォールバック

対象はPHP 8.5.12。これは完全互換の完成報告ではない。

名前空間内の非修飾の関数・定数を、ソース内の宣言有無だけでグローバル名へ書き換える方式を修正する。
構文解析時には名前空間内の名前とグローバルへのフォールバック候補を保持し、実行時に選択する。
条件付き・ネストした関数宣言、defineで作る定数、参照返却、first-class callableを対象にする。
明示的なuse、修飾名・完全修飾名には暗黙のグローバルフォールバックを追加しない。

PHP 8.5.12の実測に合わせ、同じ関数呼出し・定数参照の位置では最初の解決を保持する。
同じ名前を後から名前空間内に定義した場合も、別の参照位置は独立して解決する。
この保持は各ソースの実行状態内に限定し、別のRun呼出しと共有しない。

既存940件の定義・期待値は変更しない。追加25件の期待値は、
`tools/oracle/sources/PHP_v3_17_namespace_runtime.cases.txt` を照合専用の公式PHP8.5.12で実行して生成した。
検証入口は `ALL_PHP_v3_17_validate.ps1 -CompileCSharp`。
実行結果はリポジトリのreportsに別途記録する。
存在しない関数への失敗した検索は保持せず、後の条件付き宣言後に同じ位置へ戻った場合は再解決する。
存在しない関数の通常呼出しは引数の評価前、first-class callableは作成時にErrorとして拒否する。
実在する組込み関数の解決は、引数評価が例外になっても保持する。
内部の例外クラスを解析するときは利用者ソースの名前空間メタデータを分離し、
そのキャッシュを次のRunへ持ち越しても利用者の名前解決が混入しないようにする。

未解決項目には、重複useの拒否、include/require、ジェネレータ、属性、PHP CLI診断・終了コード、
標準ライブラリ網羅、Web実行、ネイティブ拡張ABIがある。この変更でそれらの完了を主張しない。
